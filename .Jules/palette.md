## 2025-02-12 - Product Card Action Accessibility
**Learning:** Found that the "Favorite" and "Compare" icon-only buttons in `ProductCard.tsx` were completely hidden from keyboard users because they relied solely on a `group-hover:opacity-100` pattern on their container. Furthermore, these critical interaction buttons lacked `aria-label`s, rendering them ambiguous to screen readers, which only heard the word "favorite" or "compare_arrows" due to the unhidden icon font text.
**Action:** Always pair `group-hover:opacity-100` with `focus-within:opacity-100` on containers holding interactive elements to ensure keyboard visibility. Add explicit `aria-label` attributes to icon-only buttons, hide the inner icon text from screen readers using `aria-hidden="true"`, and apply `focus-visible:ring-2` to guarantee clear focus indicators for keyboard users.
