## 2025-01-20 - Adding Accessibility to Interactive Product Cards
**Learning:** In highly customized Tailwind components like product cards where overlay action buttons are hidden by default (`opacity-0`), applying `focus-within:opacity-100` on the container is critical for keyboard accessibility. This ensures that hidden functional elements (like favorite/compare actions) become visible when a user tabs into them, preventing a "ghost focus" scenario. Also, the dynamic "Add to Cart" state changes (switching to "Added") must be coupled with `aria-live` regions to announce to screen readers properly.
**Action:** Always add `focus-within:opacity-100` alongside `group-hover:opacity-100` for concealed actionable icons, provide detailed `aria-label` and `aria-pressed` state attributes, and apply the brand color `#1089A4` for clear custom `focus-visible` ring indicators.
