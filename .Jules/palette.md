## 2026-04-22 - Marking Up Hover-Based Toggle Icon Buttons
**Learning:** When hiding action buttons visually behind a `group-hover:opacity-100` class (like favorite or compare icons on a product card), keyboard users completely miss them because tabbing to them doesn't reveal them visually. Additionally, pure icon buttons acting as state toggles need both `aria-label` and `aria-pressed` for screen readers to properly understand their purpose and current state.
**Action:** Always pair `group-hover:opacity-100` with `focus-within:opacity-100` on the container so the buttons appear during keyboard navigation. Also, add explicit `focus-visible:ring-2` styles so the focus indicator is clear. Ensure toggle icon buttons have `aria-label` and `aria-pressed={boolean}` attributes.
