## 2024-05-18 - Improve quick action buttons accessibility in ProductCard
**Learning:** Icon-only quick actions (Favorite/Compare) were hidden behind a generic `opacity-0 group-hover:opacity-100` state and lacked ARIA labels and `aria-pressed` toggle states. The localized text from the existing `title` attribute provided excellent native text for the ARIA labels, allowing for accurate non-English localization in screen readers.
**Action:** Always verify that actionable overlay items are accessible via keyboard focus by adding `focus-within:opacity-100` to the hidden container. Use `aria-pressed` for explicit state toggles (like favoriting) and `focus-visible:ring-2 outline-none` to make the keyboard focus state clear. Reuse existing localized `title` text for `aria-label`.
