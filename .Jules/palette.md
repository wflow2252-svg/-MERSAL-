## 2024-05-15 - Product Card Accessibility and Keyboard Navigation
**Learning:** Using `focus-within:opacity-100` on containers alongside `group-hover:opacity-100` is critical for ensuring quick actions are discoverable by keyboard-only users. Furthermore, relying on exact localized titles (e.g. Arabic) instead of assuming translations for toggle buttons, and reflecting the toggle state with `aria-pressed` avoids translation assumptions and improves accessibility. Using `aria-live` on add-to-cart buttons ensures proper screen reader feedback on dynamic updates.
**Action:** When adding hover-revealed elements in UI components, always apply `focus-within` styling to their container. For toggle buttons, use `aria-pressed` instead of alternating `title` or `aria-label` texts, and add `aria-live` to dynamic action buttons.
