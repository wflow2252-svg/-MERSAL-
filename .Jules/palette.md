## 2024-05-18 - Missing ARIA Labels in Icon-Only Buttons\n**Learning:** The `ProductCard.tsx` and other UI components often use tooltips via the `title` attribute, but lack actual `aria-label` attributes for screen reader accessibility on icon-only buttons.\n**Action:** Always ensure that icon-only interactive elements contain an `aria-label`, preferably dynamic to reflect the action state (e.g., 'Add to Favorites' vs 'Remove from Favorites').
