## 2026-06-17 - Icon-only buttons and state announcements
**Learning:** Icon-only buttons for actions like "Favorite" or "Compare" lack context for screen readers and visually hidden focus indicators make keyboard navigation difficult. Furthermore, state changes like "Added to Cart" need to be announced immediately to visually impaired users to confirm action success.
**Action:** Always add descriptive, dynamic `aria-label` or `title` attributes (e.g. "Add to Favorites" vs "Remove from Favorites") to icon buttons. Consistently apply `focus-visible:ring-2 focus-visible:ring-[#1089A4] focus-visible:outline-none` for keyboard focus states across buttons and links. Use `aria-live="polite"` and `aria-atomic="true"` on dynamic action buttons (like "Add to Cart") so screen readers can naturally announce the state change without interrupting other flows.
