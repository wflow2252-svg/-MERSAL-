## 2024-06-27 - Keyboard Navigation for Hover-Only UI Elements
**Learning:** Container elements that reveal interactive children (like icon-only actions) only on hover (`opacity-0 group-hover:opacity-100`) completely hide those actions from keyboard-only users who navigate via Tab. The child items can receive focus, but remain invisible, creating a broken experience. Furthermore, icon-only buttons often lack descriptive text for screen readers if `aria-label` is not explicitly provided.
**Action:** Always add `focus-within:opacity-100` alongside `group-hover:opacity-100` on containers to ensure hidden actions become visible when their children receive keyboard focus. Always add descriptive `aria-label`s and proper focus indicators (`focus-visible:ring-2 focus-visible:ring-[#1089A4] outline-none`) to icon-only buttons.
