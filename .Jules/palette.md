## 2025-03-01 - Enhance hover-based icon actions visibility for keyboard users
**Learning:** In e-commerce product cards, floating action items (like 'Favorite' and 'Compare' buttons) that are hidden by default and only visible via `opacity-0 group-hover:opacity-100` create a critical accessibility barrier. Keyboard-only users who navigate via <kbd>Tab</kbd> focus on the element, but it remains invisible (or leaves a confusing ghost focus state) because they aren't hovering over the parent group. Additionally, relying strictly on `title` attributes for toggled icon buttons leaves screen reader users guessing the current active state.
**Action:** When creating or modifying reveal-on-hover containers, always pair `group-hover:opacity-100` with `focus-within:opacity-100` so the entire container becomes visible when an interactive child element receives focus. For icon toggle actions, enforce explicit `aria-pressed={boolean}` states and ensure a strong, high-contrast focus indicator (e.g., `focus-visible:ring-2 focus-visible:ring-[#1089A4]`) is applied to guide keyboard users efficiently.
