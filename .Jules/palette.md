## 2026-04-22 - Product Card Interactive Element Accessibility
**Learning:** Toggle-based icon buttons (favorite/compare) lack context for screen readers when only indicated by colors/icons, and dynamically appearing elements (add to cart status) are missed by screen readers without ARIA live regions. Additionally, hover-revealed containers (quick actions) are unreachable via keyboard without `focus-within` styling, hiding critical functions from non-mouse users.
**Action:** When implementing icon toggles, always use `aria-pressed` and `aria-label` that update based on state. For hover-reveal container actions, pair `group-hover` with `focus-within` so keyboard navigation expands them. Apply `aria-live="polite"` and `aria-atomic="true"` on dynamic action buttons (like add-to-cart) to announce text changes (e.g. "Added"), and ensure all interactive elements have explicit focus rings (`focus-visible:ring-2`) and hidden decorative icons (`aria-hidden="true"`).
