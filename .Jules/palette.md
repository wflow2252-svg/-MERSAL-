## 2026-06-20 - ProductCard Accessibility\n**Learning:** Icon-only buttons for actions like Favorite/Compare must include `aria-label`s and focus states (`focus-visible`). The container needs `focus-within:opacity-100` so elements appear when tabbed to, even if they are only visible on hover initially. Also, dynamic state changes on buttons (like 'Add to Cart' becoming 'Added') should use `aria-live='polite'` to notify screen readers smoothly.\n**Action:** Always include `aria-label` and `focus-visible` utility classes for icon-only action buttons. Remember to use `focus-within:opacity-100` for containers with hover-only children to ensure keyboard navigation visibility.
