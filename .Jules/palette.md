## 2024-07-10 - Keyboard Navigation and Dynamic Screen Reader Announcements
**Learning:** Absolute-positioned quick action buttons (like Favorite/Compare) often use `opacity-0` on their container until hovered, making them inaccessible to keyboard users navigating via Tab. Screen readers need dynamic announcements for temporary states (like an "Added to Cart" success confirmation) instead of just visual changes. Material Symbol icon fonts can add unnecessary noise if not hidden from screen readers.
**Action:** Always add `focus-within:opacity-100` to containers that use `opacity-0` for hover effects to ensure visibility during keyboard navigation. Add `focus-visible:ring-*` for clear focus indicators. Use `aria-label`s on icon-only buttons and set `aria-hidden="true"` on the icon `<span>` itself. Use `aria-live="polite"` and `aria-atomic="true"` on buttons that dynamically change text to announce localized state transitions to screen readers.
