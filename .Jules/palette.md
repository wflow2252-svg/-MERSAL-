## 2026-04-21 - [Added Focus Styles and ARIA to ProductCard Icon Buttons]
**Learning:** When using Playwright to verify focus-within styling (like making hidden action buttons visible on keyboard focus), native `locator.focus()` might fail or timeout on elements that are initially hidden (opacity-0). Using `page.evaluate()` to directly invoke `.focus()` via JS is more reliable in headless scripts. Additionally, isolating UI components into a static HTML structure is often quicker and cleaner for visual verification than spinning up the entire Next.js app, especially if there are hydration issues or DB dependencies.
**Action:** Next time I need to test focus states on elements with tricky visibility (like `group-hover:opacity-100 focus-within:opacity-100`), I'll prefer a mocked HTML environment and use raw JS `evaluate` for focusing if Playwright struggles.
